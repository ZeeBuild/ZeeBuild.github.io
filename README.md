# Zee Site

A lightweight static site — plain HTML, CSS and JS. No build step, no dependencies.

## Structure

```
index.html   — the page
style.css    — styles
```

## Run locally

Open `index.html` in a browser, or serve it:

```bash
npx serve .
```

## Deploy

Works as-is on GitHub Pages, Netlify, Cloudflare Pages, or any static host.
